# TinyPost 业务规则

> 业务 profile 自有规则，随激活链挂载到 .claude/rules/。

## 产品红线（CRITICAL）

| # | 规则 |
|---|------|
| TP-BR-01 | 离线优先：禁止引入任何遥测、崩溃上报、云同步、外发统计请求；所有网络访问仅限用户显式发起的目标请求 |
| TP-BR-02 | 敏感数据（token、密码、cookie、客户端证书路径）仅存本机 SQLite，禁止明文写入日志或导出到备份之外的任何位置 |
| TP-BR-03 | 双平台等价：任何功能在 Windows x64 与麒麟 V10 SP3 arm64 上行为一致；禁止引入平台原生模块依赖（依赖必须 WASM/纯 JS） |

## 业务语义规则

| # | 规则 |
|---|------|
| TP-BR-04 | 环境互斥：同一时刻仅一个环境激活；变量渲染、cookie 携带、TLS 证书均取自激活环境 |
| TP-BR-05 | Cookie 罐按环境隔离；仅当响应包含 Set-Cookie 时写入，请求发出前按 URL 匹配携带 |
| TP-BR-06 | 集合运行严格按请求项 sort_order 串行执行；未标记「参与运行」（meta.runEnabled）的请求项不执行；提取规则写回环境后供后续请求使用；任一步非 2xx 或二进制响应即停止推进且不做提取 |
| TP-BR-07 | `{{var}}` 渲染发生在请求发出前，作用于 URL/Query/Headers/Body；未定义变量原样保留并在结果中可辨识 |
| TP-BR-08 | insecure（跳过 TLS 校验）默认关闭，属用户显式选择；开启状态须在 UI 可见 |
| TP-BR-09 | 二进制响应体不进文本渲染管线，仅提供「另存为」；文本响应按 Content-Type 格式化 |
| TP-BR-10 | 历史与集合数据全部软依赖时间倒序/排序号，删除即物理删除（本地工具，无审计诉求） |
