## 1. 业务概念解析（0.1）

| 维度 | 提取结果 |
|------|---------|
| 业务术语 | 请求、集合、请求项、环境、变量、历史、提取规则、Cookie 罐、集合运行、便携备份（详见知识库 business-concepts） |
| 业务流程 | 构建请求 →（环境变量渲染）→ 发送 → 响应检视/落盘 →（提取规则回写环境）→ 下一请求；登录链：登录接口 → 提取 token → 后续请求携带 |

| 业务规则 | 离线零外发（TP-BR-01）、敏感数据不出本机（TP-BR-02）、双平台等价（TP-BR-03）、环境互斥（TP-BR-04）等，全量见挂载规则 tinypost-business-rules.md |
| 业务数据 | 请求定义（method/url/headers/body/auth/query/meta）、集合与排序、环境（变量/TLS/Cookie 罐）、历史快照、应用设置；持久化为 5 张 SQLite 表 |

## 4. 逐项澄清结果（0.4，按优先级）

| # | 澄清点 | 结论（依据：代码/README） |
|---|--------|--------------------------|
| 1 | 业务边界 | 单机桌面工具域：本地 API 调试。不涉及服务端部署、团队协作、云同步（TP-BR-01 红线） |
| 2 | 用户类型 | 仅「API 调试者」一类，全功能可见；无角色/权限分层（无登录体系） |
| 3 | 核心实体与关系 | 集合 1:N 请求项（sort_order 有序）；环境 1:1 Cookie 罐、1:N 变量、0..1 TLS 配置；历史与请求定义弱关联（快照含完整入参出参）；请求项 meta 内嵌提取规则/表单字段 |
| 4 | 状态流转 | 无持久业务状态机。运行时态：请求（待发送→发送中→完成/失败/已取消）；环境（激活/未激活，全局唯一激活）；请求项（启用/跳过，TP-BR-06） |
| 5 | 业务规则 | 见 §1 业务规则行；关键：变量渲染时机（发出前，作用于 URL/Query/Headers/Body，TP-BR-07）、insecure 默认关闭且 UI 可见（TP-BR-08）、二进制仅另存为（TP-BR-09） |
| 6 | 集成关系 | ① 对外单向：任意目标系统 HTTP/HTTPS（含自签证书、客户端证书、Basic/Bearer/APIKey）；② 数据入站：Postman Collection v2.1、cURL 命令、便携备份文件；③ 出站：响应体/整库备份落本机文件系统 |
