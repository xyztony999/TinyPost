## 第一部分：文档概述

本文档按用户类型列出 TinyPost 全部可操作菜单与功能点，作为功能开发核对与后续交互设计（D4 PageSpec）的输入。

### 1.1 背景与目标

TinyPost 为单一用户类型的本地工具，功能清单的目标是把应用架构（AA）中的每个功能子模块展开为具体菜单与功能点，保证 AA→FL 全覆盖、可追溯。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | 本地 API 调试域 |
| 用户类型 | API 调试者 |
| 排除 | 平台支撑域（纯技术功能，不体现为用户菜单） |

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

仅一类用户「API 调试者」，覆盖核心业务域（请求构建与发送、集合运行）、支撑业务域（集合管理、环境与变量、会话保持、历史记录、导入导出）与基础数据域（应用设置）全部 21 个功能子模块；平台支撑域不设用户菜单。

## 2.1 API 调试者

**用户类型概述**：内网/信创环境的开发联调人员，使用 TinyPost 构建请求、调试接口、编排登录链、管理调试资产；全功能可见。

#### 2.1.1 核心业务域

**应用域概述**：调试主链——单请求构建发送与集合链路回放。

##### 2.1.1.1 请求构建与发送（C-01）

**功能说明**：定义并执行单次 HTTP 调用并检视、落盘响应。

###### 请求编辑

**功能说明**：编辑请求定义的全部要素。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 请求编辑器 | 编辑方法（GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS）、URL、查询参数、请求头 | 请求编辑 | |
| 请求体编辑 | 三种体模式：raw 文本（CodeMirror）、form-data（text/file 字段）、urlencoded 键值对 | 请求编辑 | |
| 认证配置 | Bearer / Basic / API Key / 无认证，四选一 | 请求编辑 | |
| 请求级 TLS/选项 | 请求级证书路径与超时等执行选项覆盖 | 请求编辑 | |
| 保存为请求项 | 把当前编辑内容保存/更新到指定集合 | 请求编辑 | |

###### 请求执行

**功能说明**：渲染变量并发出请求。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 发送 | 按激活环境渲染 `{{变量}}`（URL/Query/Header/Body）后发出请求 | 请求执行 | |
| 取消 | 中止进行中的请求 | 请求执行 | |

###### 响应检视

**功能说明**：完整呈现响应。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 响应查看 | 状态码/响应头/响应体（按 Content-Type 格式化）/耗时/大小 | 响应检视 | |
| 重定向链查看 | 逐跳展示重定向状态与 Location | 响应检视 | |
| Set-Cookie 事件查看 | 展示本次响应写入 Cookie 罐的条目 | 响应检视 | |

###### 响应落盘

**功能说明**：响应体文件化。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 响应另存为 | 响应体（含二进制）另存为本机文件 | 响应落盘 | 二进制不走文本渲染 |

##### 2.1.1.2 集合运行（C-02）

**功能说明**：链路编排与整链回放。

###### 运行编排

**功能说明**：确定参与运行的请求项。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 参与运行开关 | 标记集合内某请求项是否参与运行，不参与的运行时跳过 | 运行编排 | 存于请求项 meta.runEnabled |
| 运行入口 | 选择集合并按当前顺序启动运行 | 运行编排 | |

###### 链路执行

**功能说明**：串行执行与结果呈现。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 运行集合 | 按顺序串行执行参与运行的请求项；任一步非 2xx/二进制即止 | 链路执行 | |
| 运行结果面板 | 逐步展示每个请求项的请求/响应/耗时/成败 | 链路执行 | |
| 中止运行 | 停止后续步骤 | 链路执行 | |

###### 提取回写

**功能说明**：响应值回写环境变量。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 提取规则配置 | 为请求项配置 JSONPath 提取规则（可多条、可启停） | 提取回写 | 存于请求项 meta |
| 提取结果查看 | 运行后展示每条规则的提取值与写入结果 | 提取回写 | |
