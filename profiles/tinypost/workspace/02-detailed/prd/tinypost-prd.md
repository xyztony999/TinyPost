| 属性 | 值 |
|------|-----|
| 版本 | v1.0 |
| 状态 | 稳定 |
| 最后更新 | 2026-10-27 |
| 覆盖模块 | tinypost（全产品基线建档） |

## 1. 业务目标（G1）

**解决什么问题**：内网/信创（麒麟 V10 SP3 arm64）环境缺少可离线使用的 API 调试工具——云客户端不可用、浏览器受 CORS 与证书策略限制、登录链路（登录取 token → 后续请求携带）无法整链回放。

**为谁**：内网与信创环境的开发/联调人员（单一用户类型：API 调试者）。

**业务价值**：把构建请求 → 发送 → 检视 → 沉淀资产 → 整链回放的完整调试工作流收进一个本地桌面应用；数据全本机（SQLite），敏感信息不出本机；Windows x64 与麒麟 arm64 双平台行为一致。

## 2. 功能范围（G2）

### 2.1 做什么

| 模块 | 功能范围 |
|------|---------|
| 请求构建与发送（C-01） | 方法/URL/查询参数/请求头/请求体（raw、form-data 含文件、urlencoded）/认证（Bearer/Basic/API Key）/请求级 TLS；变量渲染后发送，可取消；响应完整检视（状态/头/体/耗时/大小/重定向链/Set-Cookie）；响应体（含二进制）另存为 |
| 集合运行（C-02） | 集合内请求项按序串行执行；可标记不参与运行；提取规则（JSONPath）回写环境变量；逐步结果呈现；任一步非 2xx/二进制即中止 |
| 集合管理（S-01） | 集合增删改名；请求项保存/改名/删除；拖拽排序持久化 |
| 环境与变量（S-02） | 环境增删改查；全局唯一激活切换；`{{key}}` 变量维护；环境级 TLS 证书路径 |
| 会话保持（S-03） | 环境级 Cookie 罐：自动收集 Set-Cookie、按 URL 匹配携带；环境间隔离 |
| 历史记录（S-04） | 每次发送自动留档完整快照；时间倒序浏览；一键回填；清空 |
| 导入导出（S-05） | Postman Collection v2.1 导入；cURL 命令导入；整库单文件备份/恢复 |
| 应用设置（D-01） | 超时、跳过 TLS 校验、跟随重定向、明暗主题（跟随系统） |

### 2.2 不做什么

- 不做云同步、团队协作、账号体系、遥测/崩溃上报（红线 TP-BR-01）
- 不做接口自动化测试断言引擎、性能压测、Mock Server
- 不做 GraphQL/gRPC/WebSocket 调试（第一期仅 REST）
- 不做代理抓包、请求拦截改写
- 不做多用户与权限体系（单机单用户）
- 不支持 macOS/Linux x86 以外平台的自适应打包（仅 win-x64、kylin-arm64）

## 3. 角色定义（G3）

| 角色 | 职责 | 权限 |
|------|------|------|
| API 调试者 | 全部功能的操作者 | 全功能（无权限分层，本地单用户） |

## 4. 领域对象与关系（G4/G5）

| 对象 | 说明 | 关系 |
|------|------|------|
| 集合 Collection | 请求项的有序容器 | 1:N 请求项；删除级联 |
| 请求项 SavedRequest | 持久化的请求定义 + 顺序 + 跳过标记（meta 内） | N:1 集合 |
| 请求定义要素 | 方法/URL/头/体/认证/查询/meta（值对象群，内嵌请求项与历史） | 内嵌 |
| 环境 Environment | 变量集合 + TLS 配置 + Cookie 罐 + 激活态 | 全局唯一激活 |
| 变量 VariableItem | 键值对 | N:1 环境 |
| Cookie 罐 CookieJar | 环境内 Cookie 条目集合 | 1:1 环境 |
| 历史条目 HistoryEntry | 一次发送的完整快照（含 meta/auth/query） | 独立，创建后不可变 |
| 集合运行 CollectionRun | 一次链路回放过程（子流程，不持久化） | 编排集合内请求项；输出回写环境 |
| 应用设置 AppSettings | 键值存储（settings 表） | 全局 |

> 详细分类（聚合根/实体/值对象/子流程/过程数据）见 [tinypost-domain-model.md](tinypost-domain-model.md)。

## 5. 分模块需求

### 5.1 请求构建与发送

**业务字段（T1）**：method（HttpMethod 七值）、url、headers[]（key/value/enabled）、query[]（key/value/enabled）、bodyMode（raw/form-data/urlencoded）、body（raw 文本）、formFields[]（key/type=text|file/value/fileName/contentType/enabled）、urlencodedFields[]（key/value/enabled）、auth（type=bearer|basic|apikey|none + 各类型字段）、meta（提取规则、参与运行标记等）、执行选项（timeoutMs、insecure、followRedirects、tls）。

**业务规则**：
- 变量渲染发生在发出前，作用于 URL/查询参数/请求头/请求体；未定义变量原样保留（TP-BR-07）
- insecure 默认关闭；开启后状态须在 UI 可见（TP-BR-08）
- 二进制响应不走文本渲染，仅「另存为」（TP-BR-09）
- 请求级 TLS 选项优先于环境级配置

### 5.2 集合运行

**业务规则**：
- 严格按 sort_order 串行执行；未标记参与运行（meta.runEnabled）的请求项不执行（TP-BR-06）；任一步非 2xx 或二进制响应即中止且不做提取
- 每步执行后应用该请求项的提取规则（JSONPath），命中的值写回激活环境变量，供后续步骤渲染
- 中止后已完成的步骤与已回写的变量保留

### 5.3 集合管理 / 环境与变量 / 会话保持

**业务字段**：集合（name）；请求项（name/method/url/headers/body/auth/query/meta/sort_order）；环境（name、variables[]、tls{certPath,keyPath,caPath}、cookies、is_active）。

**业务规则**：
- 环境互斥：仅一个激活（TP-BR-04）；切换即整体切换变量/会话/证书上下文
- Cookie 罐按环境隔离；仅 Set-Cookie 写入，按 URL 匹配携带（TP-BR-05）
- 删除集合级联删除请求项；环境名唯一（UNIQUE 约束）

### 5.4 历史记录

**查询筛选（T4）**：时间倒序、limit 条数限制；列表字段：method/url/status/duration_ms/created_at。
**导出需求（T5）**：无列表导出（判定见 §9：N/A；快照内响应体可单条另存为，见 D4「响应另存为」菜单）。

### 5.5 导入导出

**对接格式（T6/T7）**：Postman Collection v2.1（JSON：集合/请求项/变量映射）、cURL 命令行（方法/URL/头/体/认证解析映射）、便携备份（SQLite 整库文件）。
**幂等策略（T8）**：导入不去重（同名集合可并存）；备份恢复为整库覆盖，覆盖前二次确认。

### 5.6 应用设置

timeoutMs（默认 60000）、insecure（默认 false）、followRedirects（默认 true）、主题（跟随系统）。

## 6. 非功能性要求（N1）

- 启动到可用 ≤ 3s（本机 SQLite 直读）；单请求开销以目标服务耗时为主，工具自身开销可忽略
- 数据量级：单机使用，历史千级、请求项百级；SQLite 单文件足够
- 双平台等价（TP-BR-03）：依赖必须 WASM/纯 JS，禁止原生模块
- 麒麟 arm64 产物：AppImage + deb（pack-deb.sh）

## 7. 异常场景（N2）

| 场景 | 处理 |
|------|------|
| 网络失败/超时 | 历史仍留档，status=null，错误信息呈现 |
| 自签证书 | insecure 开关显式开启后放行 |
| 响应体过大/二进制 | 不进文本渲染，提示另存为 |
| 备份恢复冲突 | 覆盖前二次确认；恢复后重载全部数据 |
| 变量缺失 | 原样保留 `{{key}}`，结果中可辨识 |

## 8. 历史需求（N4）

历史快照含 meta/auth/query（迁移列），保证回填后行为与当时一致；无状态变更审计诉求（本地工具，TP-BR-10）。
