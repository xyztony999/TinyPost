TinyPost 标志草案

从代码读到的品牌：轻量本地 API 客户端，不上云，数据留在本机，给内网和信创桌面用。下面八个方向都不用信封，也不用现有的字母 P。

1 端口

左边是本机，右边是一个空心端口。请求从这里发出，但不画箭头。

2 斜杠

一条路径。图标就是 URL 里的那个 /，给 API 工具用。

3 载荷

花括号夹着一小块请求体。说的是你正在调试的那份 JSON。

4 字标

任务栏里只放 tp 两个字母，全称留在旁边。不画符号。

5 界内

圆是内网边界，里面的方块是这台电脑。数据不出圈。

6 来回

两根竖条，一短一长。短的是请求，长的是响应。

7 回路

一条开口的线，在本机绕一圈就停住。对应不上云。

8 状态

一行请求加一个状态点。小尺寸里也还是「发出去了」。
